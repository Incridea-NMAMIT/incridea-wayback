# Incridea 2022 Wayback

Isolated source snapshot of [swasthikshetty10/Incridea22](https://github.com/swasthikshetty10/Incridea22), archived from commit `6c9ac1ae7c01c63ddbf03a373ce84d8d3621aab5` (2022-11-04).

The historical Firebase authentication, registration, and payment integrations are disabled. The retained site is read-only.

## Build

```sh
npm ci
npm run build:archive
```

Deploy this directory as the root of its own Vercel project for the 2022 Wayback host.
